 DashBoard
Um projeto de dashboard desenvolvido em Python, com o objetivo de visualizar e analisar dados de forma eficiente e interativa.

🧩 Estrutura do Projeto
config.py: Arquivo de configuração principal do projeto. Contém definições de parâmetros, caminhos de arquivos e outras variáveis essenciais para o funcionamento do dashboard.
